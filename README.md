# Md. Jubair Hasan Khalid — Portfolio Starter

## Preview locally
1. Extract this ZIP file to a folder.
2. Open `index.html` in Chrome or another browser.
3. Edit `index.html` to update text and links; edit `style.css` to change design.

## Before publishing
- Replace the generic LinkedIn and GitHub URLs with your actual profile links.
- Replace `your.email@example.com` with your professional email.
- Add your CV at `assets/cv.pdf` or remove the CV button until you have uploaded one.
- Verify all project descriptions and publication links.
- Do not upload confidential employer data, private dashboards, applicant information, or proprietary screenshots. Use anonymized or sample data and obtain permission before showing work created for an employer.
- The AgriTech section is intentionally described as a future vision; update it as you complete real experiments.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `jubair-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and any assets folder to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; use the URL shown in the Pages settings.

This is a static HTML/CSS/JavaScript site; no paid hosting is required for GitHub Pages.
